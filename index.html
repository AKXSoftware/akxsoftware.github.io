BookArchive

BookArchive is a lightweight desktop application designed to help you catalogue, search, and manage your personal book collection.

Key Features

  • Add books manually or by ISBN
  • Automatic metadata lookup (title, author, cover) using OpenLibrary and Google Books
  • Search and filter your collection
  • Track reading status and notes
  • Bulk import support via CSV files
  • Backup and restore the database using JSON files
